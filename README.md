
# 🧮 Kalkulator IT

Aplikasi kalkulator sederhana berbasis Web yang dibuat menggunakan **HTML, CSS, dan JavaScript**. Project ini memiliki tampilan modern dengan desain menyerupai kalkulator smartphone serta dilengkapi fitur operasi matematika dasar.

## 📌 Tentang Project

Kalkulator IT merupakan project sederhana untuk mempelajari dasar-dasar pengembangan aplikasi web (Web Development), khususnya penggunaan HTML sebagai struktur halaman, CSS untuk desain antarmuka, dan JavaScript untuk logika perhitungan.

Menariknya, aplikasi ini memiliki fitur khusus berupa pesan ucapan ulang tahun ketika pengguna memasukkan operasi `18+1`.

## ✨ Fitur

- ➕ Penjumlahan
- ➖ Pengurangan
- ✖️ Perkalian
- ➗ Pembagian
- 📊 Operasi persentase (%)
- 🔢 Bilangan desimal
- 🧹 Tombol Clear (C)
- ⚖️ Tombol hasil perhitungan (=)
- ❤️ Pesan spesial ulang tahun melalui operasi `18+1`
- 🎨 Tampilan sederhana dan modern
- 💻 Dapat dijalankan langsung melalui browser

## 🛠️ Teknologi yang Digunakan

| Teknologi | Fungsi |
|---|---|
| HTML5 | Membuat struktur halaman |
| CSS3 | Mengatur tampilan dan desain kalkulator |
| JavaScript | Mengatur fungsi dan logika perhitungan |

## 🚀 Cara Menjalankan Project

1. Clone repository ini:

   ```bash
   git clone https://github.com/USERNAME/Kalkulator-IT.git
   ```

2. Masuk ke folder project:

   ```bash
   cd Kalkulator-IT
   ```

3. Buka file `index.html` menggunakan browser.

4. Kalkulator siap digunakan!

## 🎯 Cara Menggunakan

1. Klik angka yang ingin dihitung.
2. Pilih operator matematika (+, -, ×, /).
3. Masukkan angka berikutnya.
4. Tekan tombol `=` untuk menampilkan hasil.
5. Tekan tombol `C` untuk menghapus perhitungan.

**Fitur Spesial:**

Masukkan operasi berikut:

```text
18 + 1 =
```

Maka kalkulator akan menampilkan pesan:

```text
SELAMAT ULANG TAHUN SAYANG AKU ❤️
```
